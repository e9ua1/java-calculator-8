# 문자열 덧셈 계산기

## 프로젝트 개요
입력한 문자열에서 숫자를 추출하여 덧셈을 수행하는 계산기입니다.
기본 구분자(쉼표, 콜론)와 사용자 정의 커스텀 구분자를 지원하며,
잘못된 입력에 대한 예외 처리를 포함합니다.

## 주요 기능
- 쉼표(,) 또는 콜론(:)을 구분자로 하는 숫자 덧셈
- 커스텀 구분자 지정 기능 (`//구분자\n숫자` 형식)
- 음수 및 잘못된 입력에 대한 예외 처리
- 빈 문자열 입력 시 0 반환

## 실행 예시
```
덧셈할 문자열을 입력해 주세요.
1,2:3
결과 : 6
```

```
덧셈할 문자열을 입력해 주세요.
//;\n1;2;3
결과 : 6
```

## 개발 환경
- JDK 21
- JUnit 5
- AssertJ

## 기능 목록

### 1. 입력 처리
- [ ] 사용자로부터 문자열 입력받기
- [ ] 빈 문자열 처리 (결과: 0)

### 2. 기본 구분자 처리
- [ ] 쉼표(,) 구분자로 숫자 분리
- [ ] 콜론(:) 구분자로 숫자 분리
- [ ] 쉼표와 콜론 혼합 사용

### 3. 커스텀 구분자 처리
- [ ] "//"와 "\n" 사이의 문자를 커스텀 구분자로 인식
- [ ] 커스텀 구분자로 숫자 분리

### 4. 계산
- [ ] 분리된 숫자들의 합 계산

### 5. 예외 처리
- [ ] 음수 입력 시 IllegalArgumentException 발생
- [ ] 잘못된 형식 입력 시 IllegalArgumentException 발생

### 6. 출력
- [ ] "결과 : {숫자}" 형식으로 출력
